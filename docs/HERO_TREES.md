# Hero upgrade trees

**Status: Proposed, planned 2026-11-01, not built yet.** The owner's rules are Decided: a tree for
each hero, gold plus four crystals, everything unlockable up to a point, and a two-week reset
beyond it. Every name, number and ability here is a draft to confirm.

These replace hero levels and perks. Today's signature moves all live on as dark-crystal capstones.

## How a tree works

Every hero has the same shape, 13 upgrades in all. An upgrade needs the one before it.

```
                     ┌─ tier 3 ── tier 4 ─┐
          ┌─ tier 2 ─┤                    ├─ capstone
          │          └─ tier 3 ── tier 4 ─┘
 start ───┤
          │          ┌─ tier 3 ── tier 4 ─┐
          └─ tier 2 ─┤                    ├─ capstone
                     └─ tier 3 ── tier 4 ─┘
```

A capstone needs just one of the two tier 4 upgrades below it, and everything can be bought in the
end.

| Tier         | Gold  | Crystals |
| ------------ | ----- | -------- |
| 1            | 150   | 1        |
| 2            | 400   | 2        |
| 3            | 900   | 3        |
| 4            | 2,000 | 5        |
| 5 (capstone) | 4,000 | 8        |

- **Nature** buys health and healing.
- **Fire** buys damage, fire rate and range.
- **Ice** buys speed: moving, moving while firing, and how fast shots fly.
- **Dark** buys new abilities.

Enemy headquarters should drop crystals in about those shares: 23% nature, 38% fire,
17% ice and 22% dark. Each island shows its crystal on its card, so players can go
after what they need.

| Base   | Crystals on a win |
| ------ | ----------------- |
| Easy   | 0-1               |
| Fair   | 1                 |
| Hard   | 1-2               |
| Deadly | 1-3               |

At about 1.3 crystals a win, that's roughly 290 wins to finish every tree, or
3 months at 3 wins a day. A first capstone costs 19 crystals: about 15 wins.

## The two-week reset: Tides

Past a hero's capstones lies their **Tide**: three upgrades that last two weeks, then lock again as
the next Tide rolls in. A hero's Tide opens once they own a capstone, so nobody has to finish a whole
tree first.

- Every hero gets the same Tide at the same time. It's worked out from the date, so it needs no
  server and works offline.
- The first two upgrades are shared by every hero. The third is that hero's own twist.
- Crystals spent on a Tide aren't refunded. That gives crystals a use once the trees are full.
- Tides work in raids, solo or with a crew, and never for night raiders.
- The six Tides come round in a shuffled order, and all six run before any repeats. New ones are
  just more rows of data.

| Upgrade      | Gold  | Crystals                         |
| ------------ | ----- | -------------------------------- |
| First        | 2,000 | 3 of the Tide's crystal          |
| Second       | 3,000 | 4 of the Tide's crystal + 1 dark |
| Hero's twist | 5,000 | 5 of the Tide's crystal + 3 dark |

## What building it involves

- The save swaps hero levels for each hero's owned upgrades, and adds a crystal wallet. Gold already
  spent on levels is handed back when an old save loads.
- A raid seat carries the upgrades a player owns, so crewmates' heroes are right on the host's phone.
- Enrage, shields, ghosts, lightning and burning ground are new rules. Plain stat upgrades only need
  numbers.
